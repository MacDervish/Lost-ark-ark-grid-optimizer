# Lost-ark-ark-grid-optimizer
Lets you set core rarity, add astrogems, pick specific targets, and then gives you a list of astrogem combos to to reach those targets

you can also set secondary stats for each individual astrogem, then set which stats you want to prioritize under advanced settings
this will give you the combination of astrogems that has the best desired secondary stat distribution whilst still reaching your targets

# Installation
You can run the program locally immediately if you have python on your pc already
  - A web client is currently in development

If you dont have python installed follow these instructions:
- Go to https://www.python.org/downloads/release/python-3143/
- Scroll down to the bottom of this page and click on the installer for your OS
- Read the instructions then download the installer
